# OpenZohoTui

Interactive terminal UI and CLI for Zoho Projects tasks and time logs.

Run without a permanent installation:

```sh
npx --yes --package=@dhyantd/open-zoho-tui@latest ozt
```

Or install the `ozt` command globally:

```sh
npm install --global @dhyantd/open-zoho-tui
ozt
```

Node.js 22 or newer is required. Your organization must deploy the OpenZohoTui
OAuth broker before login. See the
[repository documentation](https://github.com/DhyanTD/OpenZohoTUI#readme) for
configuration, deployment, and the full command reference.
